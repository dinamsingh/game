# Visual asset sources

## User-supplied Thar Roxx

Provided archive: `D:\Downloads\mahindra-thar-roxx.zip`. Its nested `source/mahindra-thar-roxx.zip` contains only `mahindra-thar-roxx.dae`, exported by SketchUp 24.0.594. No texture files, author credit or license/readme were included in that archive. This record does not establish a redistribution license for the model.

Original extracted DAE is preserved in `../ArtSource/TharRoxx/mahindra-thar-roxx.dae`.

Original DAE SHA-256: `542afa6f6b8fd3bd61100877445b278970ab1f02d7222b0c88ae1b9b2ac2c7f2`.

Working source: `Assets/Art/TharRoxx/TharRoxx.dae`. Removed 364 line groups and 712 empty/edge-only geometry entries. Surface triangles and source hierarchy are retained. `Assets/Editor/TharModelBuilder.cs` normalizes the supplied model to the game's parking footprint, corrects mirrored winding, combines meshes by surface material, and separates four tyre/wheel assemblies from their non-spinning brake hubs. The rear spare remains attached to the body. Generated runtime assets are in `Assets/Resources/Thar/`.

These Poly Haven assets use CC0: https://polyhaven.com/license . Runtime imports cap upgraded surface maps at 2048px, other maps at 1024px and the sky cubemap at 512px. Buildings, balconies, water tanks, streetlights and tree trunk/branch/card meshes are original procedural geometry generated by `EnvironmentArt.cs`. Foliage cards sample a branch region of the leaf colour/opacity atlases; the original downloaded bitmaps are unchanged.

Update 0.3.0 adds original scenery generated by `DistrictArt.cs`: workshops/shutters, container ribs and doors, wire fences, benches, drainage, barrels, crates and ridge heightfields. Brick Wall 001 diffuse MD5 `955d2d4500eb549be0f2873305782798`, normal MD5 `be151875ed0897fc716aeef6daac8bd5`; downloaded bytes match the official API metadata retained in `.tools/visual-assets/brick_wall_001.json`. Reference screenshots guided scale, materials and course variety; their pixels or game assets were not copied.

Update 0.4.0 uses original geometry in `WorkshopArt.cs`: asymmetric motor workshops with an open service bay, pitched roofs, exposed supports, office, loading canopy, tool storage, framed shipping crates and steel drums. All six new surface-map files were checked against official API byte sizes and MD5 hashes; metadata is retained in `.tools/visual-assets/{asset}.json`. The reference APK's extracted meshes/textures are not used in this kit. The supplied Thar's provenance/redistribution limitation above remains unchanged.

Raw models are under `Assets/Art/Workshop/`; metadata under `.tools/visual-assets/`. `WorkshopAssetsBuilder.cs` retains UVs/normals, combines each prop to one renderer and normalizes its bounds to a unit footprint for placement at authored metre dimensions. It rejects models over 25,000 triangles. Runtime prefab/material/mesh assets are under `Assets/Resources/Workshop/`. Generated crate/drum geometry remains a missing-resource fallback. These models are separate licensed downloads, not meshes extracted from the reference APK.

Update 0.6.0: `Tools/upgrade_surfaces.py` verifies all 16 upgraded maps against official API file size and MD5 metadata. The Editor packs inverse roughness into the alpha channel of a black metallic/smoothness texture for Unity Standard. Source maps are preserved. Road wear, sloped Jersey barriers, gantries, and the proving ground use original procedural geometry/shaders. The visual finish adds a half-resolution, eight-sample screen-space contact-shadow pass and filmic grading.
