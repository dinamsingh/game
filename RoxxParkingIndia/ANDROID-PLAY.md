# Install the Android app

Current app: Roxx Parking India 0.6.1 (versionCode 7), Android 8.0/API 26 or newer, ARM64, OpenGL ES 3. APK output is under `Builds/Android/`.

APK download: http://10.181.105.74:8877/download/RoxxParkingIndia-0.6.1.apk (52,323,912 bytes, about 52.3 MB).

Keep phone and laptop on the same Wi-Fi for the download. Open the APK link supplied in chat in phone Chrome; open the downloaded APK and choose Install (or Update if the older Roxx Parking India app is installed). If Android asks, allow APK installation for the Chrome/Files app that opens the file.

After installation, launch Roxx Parking India from the app drawer. Gameplay and progress work offline; the laptop/server is needed only to download the file. Browser progress and native app progress are separate. Existing native app progress can be retained by an in-place update with the same signing certificate.

The app includes 24 courses, 12 Expert Trials, upgraded environment surfaces/lighting, the supplied Thar, 100 km/h forward speed, and saved camera sensitivity/steering-side settings. Open CONTROLS from the main menu or Pause; choose BACK / SAVE after adjusting. Pause > Graphics has High/Balanced modes.

Build/signature/package and actual downloaded-byte verification are recorded in `Builds/Checks/apk-verification.json` and `apk-download-verification-0.6.1.json`. A new physical Android installation and app gameplay have not yet been observed. Prior High-graphics smooth feedback was for the browser build.
